# Createrington Marketing Video

A Remotion-based marketing video for Createrington (Cogs & Steam). Dark +
amber aesthetic that matches the production web client (packages/client).

## Tech

- [Remotion](https://www.remotion.dev/) 4.x
- React 18 + TypeScript
- Pure SVG/CSS — no external asset dependencies

## Install

This folder is **not** part of the pnpm workspace (see `pnpm-workspace.yaml`)
so it has its own isolated install. Run from `marketing/`:

```bash
pnpm install
# or: npm install
```

## Assets

Assets are **not** stored under `marketing/public/` in git — they're
mirrored from their authoritative locations at build time by
`scripts/sync-assets.mjs`:

| Source                                              | Destination                                 |
| --------------------------------------------------- | ------------------------------------------- |
| `packages/client/public/assets/`                    | `marketing/public/assets/`                  |
| `screenshots/` (repo root)                          | `marketing/public/screenshots/`             |
| `../parallel-worlds/.../textures/{block,item}/` ¹   | `marketing/public/assets/parallel-worlds/`  |

¹ Sibling checkout of the `parallel-worlds` mod repo; optional. If absent,
the parallel-worlds mirror is skipped (you can commit a fallback copy or
just clone the mod beside `createrington/`).

The sync runs automatically before `dev`, `build`, and `preview` via
`pre*` npm hooks. You can also run it manually:

```bash
pnpm sync-assets
```

## Preview / Edit

Launches Remotion Studio at http://localhost:3000 with a scrubber,
property editor, and hot reload:

```bash
pnpm dev
```

## Render

Produces `out/createrington-promo.mp4` (H.264, 1920x1080, 30fps):

```bash
pnpm build
```

Or WebM (VP9):

```bash
pnpm build:webm
```

## Structure

```
public/                        # Generated by scripts/sync-assets.mjs — gitignored
├── assets/hero/*.webp         # from packages/client/public/assets/hero
├── assets/features/*.webp     # from packages/client/public/assets/features
├── assets/logo/*.webp         # from packages/client/public/assets/logo
├── assets/render/*.webp       # from packages/client/public/assets/render
├── assets/parallel-worlds/    # pw_portal.png + .mcmeta from the Parallel Worlds mod
└── screenshots/*.webp         # from screenshots/ at the repo root

scripts/
└── sync-assets.mjs            # Mirrors the above; runs pre-dev/build/preview

src/
├── Root.tsx                   # Composition registration (<CreateringtonPromo>)
├── Video.tsx                  # Scene sequencing + crossfades
├── theme.ts                   # Colors, fps, scene durations
├── components/
│   ├── Background.tsx         # Ken-Burns hero image backdrop w/ gradient + glow
│   ├── BrowserFrame.tsx       # Chrome/Safari-style window wrapping screenshots
│   ├── Gear.tsx               # Procedural SVG gear (kept for future reuse)
│   ├── AnimatedCounter.tsx    # Tweened number counter (ease-out cubic)
│   ├── CandlestickChart.tsx   # Animated OHLC chart with live price cursor
│   └── assets.ts              # Central registry of asset paths (HERO_IMAGES, LOGOS, …)
└── scenes/
    ├── LogoIntro.tsx          # Real Cogs & Steam logo over dark-warehouse hero
    ├── HeroTagline.tsx        # Crossfading hero images + animated tagline words
    ├── StatsShowcase.tsx      # 4 animated stat cards on blurred space-station
    ├── FeaturesGrid.tsx       # 4 real feature cards (matches homepage exactly)
    ├── StructurePacks.tsx     # Parallel Worlds voting: pack cards + portal visual
    ├── WebShowcase.tsx        # 3 tilted BrowserFrames of real UI screenshots
    ├── CryptoMarket.tsx       # Custom chart + tickers + real portfolio screenshot
    ├── Ecosystem.tsx          # Real logos: MC / Discord / Web w/ flowing dots
    └── CallToAction.tsx       # Hero-framed "Apply Now" + createrington.com
```

Total runtime: **~46 seconds** at 30fps (1380 frames), 1920×1080.

## Customizing

- **Numbers**: `StatsShowcase.tsx` — `STATS` array. Wire to real tRPC output if desired.
- **Tickers**: `CryptoMarket.tsx` — `TICKERS` array.
- **Timings**: `theme.ts` — `DURATIONS` map. Raise/lower individual scene lengths.
- **Colors**: `theme.ts` — already mirrors the client's OkLCH palette as hex.
